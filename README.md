# خيال × خيالي — موقع تصوير وحجز

موقع عربي تجريبي متجاوب يجمع هويتين في واجهة واحدة، مع قسم مستقل لكل علامة:

- **استوديو خيال:** تصوير التخرج والمناسبات والأعراس وبرومو المشاريع وافتتاح المحلات.
- **خيالي للمنتجات:** تصوير المنتجات ومحتوى المتاجر.

الألوان والشعارات مستوحاة من ملفي الهوية المرفقين: كحلي وبيج لخيال، ووردي غباري وخمري لخيالي. أضيفت أسعار افتراضية لأغراض المشروع فقط. فريق المشروع: Beesan Natsheh وMalak Hajouj.

## فتح المشروع في Visual Studio Code

1. فكّي ضغط مجلد المشروع.
2. افتحي Visual Studio Code.
3. اختاري **File → Open Folder** ثم اختاري مجلد `khayal-photography-site`.
4. افتحي `index.html` بالمتصفح. يمكن استعمال إضافة Live Server للحصول على تحديث مباشر عند حفظ الملفات.

## معاينة الحجز

نموذج الحجز يطلب نوع التصوير والاسم ورقم التواصل والتاريخ والوقت. بعد الإرسال يعرض رقمًا تجريبيًا ويحفظ الطلب في `localStorage` في نفس المتصفح لتوضيح فكرة التأكيد اليدوي. **هذا النموذج الحالي لا يرسل الطلب إلى المصورين أو إلى قاعدة بيانات.** قبل استعمال الموقع لاستقبال حجوزات حقيقية، اربطيه برقم واتساب أو بخدمة/خادم يستقبل الطلبات، ثم غيّري رسالة النموذج بما يناسب طريقة التواصل الفعلية.

## ملاحظات

- صور المعرض الحالية صور توضيحية مستضافة خارجيًا، ويُفضّل استبدالها بصور يملكها أصحاب الصفحات.
- الأسعار تجريبية ويجب تحديثها قبل نشر نسخة تجارية.
- ارفعي الملفات الموجودة بجذر المجلد (`index.html`, `styles.css`, `script.js`, `README.md`) ومجلد `assets` معًا إلى جذر مستودع GitHub Pages.
